# `satya-py` Agent Coding & Architecture Rules

Activate [`satya-rust-workspace`](../../.agents/skills/satya-rust-workspace/SKILL.md) and [`satya-rust-engine`](../../.agents/skills/satya-rust-engine/SKILL.md) when modifying `crates/satya-py` or Python consumers in `src/satya_ml/` and `notebooks/`.

1. **Thin PyO3 (`abi3-py312`) Bridge — Zero Duplicate Math or Spatial Geometry**:
   - Module layout: `src/lib.rs` (Cascade, Triad, Rules Book, Avro/GDPR), `src/tactical_map_py.rs` (`check_tactical_token_collision`, `resolve_tactical_token_destination_cm`, `evaluate_tactical_los_and_cover`, `inspect_tactical_map_point`, `generate_procedural_tactical_sector_json`, `continue_procedural_tactical_map_json`, `switch_tactical_map_floor_json`, `extract_sector_narrative_manifest_json`, `evaluate_passive_movement_perceptions_json`), `src/hooks_and_npc_py.rs` (`compile_party_motivational_hooks_json`, `generate_npc_profile_json`), and `src/psyche_social_py.rs` (`evaluate_empathy_read_json`, `evaluate_social_exchange_json`, `resolve_cognitive_dissonance_json`, `evaluate_conviction_surge_json`, `apply_psyche_drift_mark_json`, `seed_or_update_world_ledger_json`).
   - Always delegate dice/cascade math, tactical map collision/LoS/hover geometry, passive perception checks, motivational hook compilation, social combat/Psyche mechanics, world clocks, and Avro `CRC-64-AVRO` checks to `satya-engine` and `satya-schema`. Never mutate locked `v1` structs to accommodate flexible Python dicts; normalize inputs inside `tactical_map_py.rs`, `hooks_and_npc_py.rs`, and `psyche_social_py.rs`.
2. **Windows Offline Build, `PYO3_PYTHON`, & `src\satya_py.pyd` Sync**:
   - Set `$env:PYO3_PYTHON` to an installed CPython `3.12+` interpreter (for example the active interpreter path from `python.exe` or `.pixi\envs\default\python.exe`).
   - Run `cargo clippy --offline --no-default-features -p satya-py --all-targets -- -D warnings` and `cargo test --offline --no-default-features -p satya-py` (no Python link errors in test binaries), then `cargo build --offline -p satya-py` and copy `target\debug\satya_py.dll` to `src\satya_py.pyd`.
3. **AI GM Consumers**: Follow [`src/satya_ml/ai_gm/AGENTS.md`](../../src/satya_ml/ai_gm/AGENTS.md) and [`docs/technical/ai-gm-agent-design.md`](../../docs/technical/ai-gm-agent-design.md).
