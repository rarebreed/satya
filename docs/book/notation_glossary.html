Mathematical Notation, Variables & Formula Glossary

Because Satya is a Computer-Assisted RPG (CARPG) built on an exact combinatorial and physics-grounded simulation engine, the rules chapters use consistent mathematical notation across task resolution, probability distributions, character attributes, lifepaths, action economy, combat pools, and survival mechanics.

This chapter serves as the single canonical glossary of every mathematical symbol, subscript, acronym, and formula used throughout the Satya TTRPG Rules Book. Whenever you encounter a variable such as TNP, TNGM, δunder, Dcog, or Peff in any chapter, refer here for its full name, scale, and definition.

1. Universal Subscript & Prefix Conventions

Across all equations in Satya, subscripts and prefixes follow strict naming rules so you can immediately tell who or what a variable belongs to:

Prefix / SubscriptMeaningExamples
Subscript P (_P)Player (Active Character) — Refers to the player character (or active initiator) attempting a task or contested exchange.TNP (Target Number of the Player), CP (Controlling Characteristic of the Player), NP (Skill Level of the Player), SP, BP, MP (Player Successes, Botches, Signed Margin).
Subscript GM (_GM)Game Master (Hidden Resistance / Environment) — Refers to the Game Master's hidden opposing roll representing environmental difficulty, lock/system security, or hazard virulence.TNGM (Target Number of the Game Master), CGM (Equivalent Controller of the GM), XGM (GM's 2d20 Roll Sum), SGM, BGM, MGM (GM Successes, Botches, Signed Margin).
Subscript NPC (_NPC)Non-Player Character (Active Opponent) — Refers to an active NPC opponent rolling a full opposing cascade in combat, stealth, or social duels.TNNPC (Target Number of the NPC), CNPC (NPC Controlling Characteristic), NNPC (NPC Skill Level).
Subscript n (_n)Cascade Step Index (n ∈ {1, …, N}) — Refers to the n-th sequential 2d20 dice pair in a multi-pair skill cascade.An, Bn (Die A and Die B on step n), Xn (Raw pair sum on step n), Carryn (Carry-over modifier into step n), Yn (Modified pair total on step n).
Subscript eff (_eff)Effective Value — The net value of a target number, skill rank, pool, or time cost after all situational modifiers, wounds, or synergies are applied.TNeff (Effective Uncontested Target Number), Neff (Effective Dual-Skill Rank), Peff (Effective Tactical Pool), TCeff (Effective Tick Cost).
Subscript base (_base)Baseline (Unmodified) Value — The starting value before situational, fatigue, or trauma modifiers are applied.δbase = 6 (Baseline Failure Carry), Pbase (Base Tactical Pool), TCbase (Base Tick Cost).
Subscript min / maxMinimum Floor / Maximum Ceiling — A hard lower requirement or upper physical cap.Nmin (Minimum Required Skill Level), Tmax, Cmax, Fmax (Tempo, Control, and Force Aspect Ceilings).
Capital Delta Δ (Delta_...)Additive Shift / Situational Modifier — A signed integer shift (+ or −) applied to a Target Number, Carry Penalty, or Margin.Δtool (Known Tool Modifier), Δext (Hidden External Difficulty), Δint (Internal Character Strain), Δ M (Net Contested Signed Margin).
Lowercase Delta δ (delta_...)Cascade Carry Step Size — The magnitude of momentum bonus or stumble penalty passed from Pair n to Pair n+1.δover = +6 (Positive Carry Bonus on Success), δunder = 6 + Δint (Negative Carry Penalty on Failure).

2. Core 2d20 Cascade, Task Resolution & Probability Variables

Used primarily in Probability & Calibration and Core 2d20 Cascade & Task Resolution:

2.1 Dice, Targets & Cascade Step Variables

SymbolFull NameScale / RangeDefinition & Formula
KDie Size (Faces per Die)K = 20Number of faces on each die (d20, rolling 1–20). A pair of dice (2d20) has a minimum sum of 2, a maximum sum of 2K = 40, and an exact 50% midpoint mean of K + 1 = 21.
N (or NP, NGM, NNPC)Skill Level (Number of 2d20 Pairs)0–8 (Mythic 10)Number of sequential 2d20 pairs rolled in a cascade (0 = Untrained, 1 = Novice/Talent, 3 = Competent Journeyman, 5 = Veteran Specialist, 8 = Grandmaster).
NminMinimum Skill Gate1–4Minimum Skill Level required to attempt a Class B or Class C ([Locked]) specialist task.
NparentParent / Sibling Skill Level0–8Rank in an immediate parent or sibling skill node when defaulting on a Class B task (Ndefault = max(1, Nparent − 1)).
NeffEffective Dual-Skill Level1–9Number of 2d20 pairs rolled when an action simultaneously requires two skills N1 and N2: Neff = min(N1, N2) + 1 (if |N1 − N2| ≥ 2) else min(N1, N2).
An, BnList A & List B Die Rolls at Step n1–20 eachThe two individual 20-sided dice rolled on step n ∈ {1, …, N} of the cascade. (AGM, BGM are the two d20 dice rolled secretly by the GM).
Xn (or XGM)Unmodified Pair Sum2–40The raw sum of the two d20 dice on step n before any carry-over modifier is applied: Xn = An + Bn. For the GM's hidden 1-pair roll, XGM = AGM + BGM.
CarrynStep n Carry-Over ModifierZ (0 at n=1)The momentum bonus or stumble penalty carried into Pair n from the result of Pair n−1. Always starts at Carry1 = 0 on Pair 1.
YnEffective (Modified) Pair TotalZThe total value of Pair n after adding carry-over: Yn = Xn + Carryn = An + Bn + Carryn.
YbestClosest Attempt (Maximum Pair Total)ZThe highest modified pair total achieved across all N steps: Ybest = max(Y1, Y2, …, YN). Used to determine Clean Miss (0) vs. Botch severity (-1 to -5) when SP = 0.
C (or CP, CGM, CNPC)Controlling Characteristic ("Control")1–20 (Avg 10)The governing attribute score (or composite ⌊(C1 + C2)/2⌋) for the task. Higher C lowers the Target Number by 1 per point.
ΔtoolKnown Tool & Loadout Modifier−4 to +8Transparent equipment or training modifier known to the player before rolling (-4 2033 AI smart-rig, -2 masterwork kit, 0 standard issue, +4 to +8 improvised tools or untrained default). Shifts TNP.
ΔextHidden External Task Difficulty−10 to +16Objective complexity of the obstacle or environment (-8 Trivial, -4 Easy, 0 Standard Benchmark, +4 Challenging, +8 Hard, +12 Extreme, +16 Heroic). Shifts the GM's hidden target TNGM.
ΔintInternal Character Penalty Modifier−2 to +10Internal physiological/psychological strain from Fatigue, Wound Shock, Pain, Dehydration, or Cognitive Dissonance (-2 Focused/Conviction Surge, 0 Fresh, +2 to +10 Winded to Exhausted). Increases δunder.
TN0Universal Baseline Midpoint Target21The baseline 2d20 target number for an average human (C = 10) under standard conditions (Δ = 0): TN0 = K + 1 = 21.
TNPTarget Number of the Player9–35 (Base 21)The known personal Roll-Over target the player must beat on each pair: TNP = (1.5K + 1) − CP + Δtool = 31 − CP + Δtool.
TNGMTarget Number of the Game Master5–31 (Base 21)The hidden resistance target the GM must beat on their opposing 2d20 roll: TNGM = 21 − Δext (equivalent to CGM = 10 + Δext).
TNeffEffective Uncontested Target Number5–43 (Base 21)Combined single-side benchmark target used when analyzing uncontested probability curves: TNeff = 31 − C + Δext.
δoverPositive Success Carry Bonus+6 (or +8)Momentum bonus passed to the next pair after a successful pair (Yn > TNP). Equal to 0.3K = +6 (boosted to +8 with 3+ successes on a complementary KNO setup roll).
δbaseBaseline Failure Carry Penalty6Base stumble penalty (0.3K = 6) before internal strain Δint is added.
δunderNegative Failure Carry Penalty4–16 (Base 6)Total stumble penalty magnitude subtracted from the next pair after a failed pair (Yn ≤ TNP): δunder = δbase + Δint = 6 + Δint.

2.2 Contested Outcomes, Margins & Statistical Moments

SymbolFull NameScale / RangeDefinition & Formula
SPPlayer Success Count0… NPTotal number of pairs where the player beat their personal target (Yn > TNP).
BPPlayer Floor-Breach Count0… NPNumber of failed steps where negative carry pushed the player's modified total below the physical 2d20 minimum of snake-eyes (Yn < 2, raw_botches).
BeffPlayer Effective Closest-Miss Botch Tier0… 5When SP = 0, the player's closest attempt Ybest binned into 4-point (K/5 = 4) tiers below TNP: Beff = min(5, ⌊(TNP − Ybest)/4⌋).
MPPlayer Signed Margin−5… +NPUnified signed outcome of the player's cascade: MP = +SP if SP ≥ 1; MP = 0 on a Clean Miss (SP = 0, Beff = 0); or MP = −Beff on a Botch.
SGMGM Resistance Success Count0… 5+Number of opposing successes scored by the GM. Under the 1-Pair Tiered GM Rule (4-pt over-tiers), when XGM > TNGM: SGM = 1 + ⌊(XGM − TNGM − 1)/4⌋.
BGMGM Environmental / Obstacle Botch Tier0… 5Under the 1-Pair Tiered GM Rule (4-pt under-tiers), when XGM ≤ TNGM: BGM = min(5, ⌊(TNGM − XGM)/4⌋).
MGMGM Signed Margin−5… +5+Unified signed outcome of the GM's hidden roll: MGM = +SGM if XGM > TNGM, or MGM = −BGM if XGM ≤ TNGM.
Δ MNet Contested Signed MarginZNet margin between the Player and the GM: Δ M = MP − MGM. Determines CleanSuccess (1 ≤ Δ M ≤ 2) vs. ExtraordinarySuccess (Δ M ≥ +3).
PMFProbability Mass FunctionP(X = x) ∈ [0, 1]Function giving the exact probability that a discrete random variable equals each possible integer outcome x.
E[X] (or μ)Expected Value (Mean)RProbability-weighted average outcome: E[X] = μ = ∑x x · P(X = x) (e.g., E[Margin] or E[Δ M]).
Var(X) (or σ2)VarianceR ≥ 0Expected squared deviation from the mean: σ2 = ∑x (x − μ)2 P(X = x) (where σ = √σ2 is the standard deviation).
μ3 & γ1Third Central Moment & SkewnessRMeasures distribution asymmetry: μ3 = ∑x (x − μ)3 P(X = x) and γ1 = μ3 / σ3 (γ1 > 0 = right-skewed tail; γ1 < 0 = left-skewed tail).
κexcessExcess KurtosisRMeasures tail heaviness / peak flatness relative to a normal bell curve: κexcess = (μ4 / σ4) − 3.
BCSarle's Bimodality Coefficient0.0–1.0Diagnostic metric for whether a distribution is unimodal or bimodal: BC = (γ12 + 1) / (κexcess + 3). Values BC > 0.555 (5/9) indicate a bimodal ("watershed") distribution.
