The core *Awakened* campaign documents are written to keep game sessions fast, dramatic, and intuitive at the table. This **`appendix/`** directory collects the deeper technical essays, physics mechanisms, formal logic, and real-world scholarly lineages behind the 2035 setting—giving GMs, players, and AI storytellers rigorous conceptual grounding without cluttering baseline lore chapters.

Because the engine's lore retrievers index every Markdown document under `docs/campaign/`, material placed here remains discoverable during campaign prep while keeping core chapters readable on a single pass.
